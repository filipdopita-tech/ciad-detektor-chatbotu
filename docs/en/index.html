Privacy policy

Chatbot Detector by CIAD extension · effective 31 October 2026

What the extension collects

Nothing. The extension does not collect, store or transmit any personal data, browsing history, page content or any other data. It contains no analytics, tracking, advertising or remote code.

How it works

The check runs only after you click the extension icon, and only on the current tab. A script runs inside the page, inspects its code and visible elements, and shows the result in the extension popup. The result stays in your browser and disappears when the popup closes. The extension sends nothing anywhere, stores nothing, and never opens or types into a chat window.

Permissions

  • activeTab: access to the current tab only after a user click.
  • scripting: running the check on that tab.

The extension has no host permissions, no access to browsing history, and no background process running outside your click.

The "How we measure" link

The link opens the ciad.cz page in a new tab only when you click it. The extension itself sends no data to the CIAD website.

A signal, not a legal assessment

The result is a technical signal and is not a substitute for legal advice.
